\chapter*{Resumen}

Breve resumen de las principales contribuciones del trabajo.
En este trabajo se describe y se presenta una solución con el objetivo de mejorar la eficiencia temporal en el acceso a 
nubes de puntos 3D utilizando como estructura de datos octrees lineales. El estudio consiste en el reordenamiento espacial
 de puntos para tratar de explotar la capacidad de poda a la hora de encontrar vecindades. Se evalúan resultado temporales usando diferentes técnicas de reordenamiento, usando tanto las coordenadas cartesianas como las coordenadas polares de los puntos.
